### 2.2 语言自动检测

**功能描述**:
- 用户上传SRT文件时自动检测语言
- 在文件列表中显示检测结果 (例如: `subtitle.srt [中文]`)
- 检测结果存储在列表项的UserRole+1数据中

**实现细节**:
```python
# 检测语言
detected_lang = detect_language_from_file(file_path)
lang_display = "中文" if detected_lang == "zh" else "英文" if detected_lang == "en" else "未知"

# 显示在列表中
display_name = f"{os.path.basename(file_path)} [{lang_display}]"
item.setData(Qt.ItemDataRole.UserRole + 1, detected_lang)
```

### 2.3 高级分析对话框

**功能描述**:
- 对选中的SRT文件进行多维度分析
- 使用标签页组织不同类型的分析结果

**标签页结构**:
1. **📖 叙事结构** - IntegratedNarrativeAnalyzer
   - 总片段数
   - 关键情节点
   - 情感曲线趋势
   - 场景连贯性评分
   - 剧情密度

2. **🎵 节奏分析** - RhythmAnalyzer
   - 节奏模式 (快/中/慢)
   - 平均节奏 (秒/片段)
   - 总片段数
   - 总时长
   - 节奏建议

3. **✂️ 片段建议** - SegmentAdvisor
   - 智能合并建议
   - 过短片段检测
   - 内容相关性分析
