## 二、核心机制

### 1. 硬件指纹生成

**定义**: 硬件指纹是设备的唯一标识,由以下信息组成:
- CPU核心数
- 系统内存总量(GB)
- CPU架构(x86_64/AMD64/ARM64等)

**生成方式**:
```python
import psutil
import platform

fingerprint = f"{psutil.cpu_count()}_{int(psutil.virtual_memory().total/1024**3)}_{platform.machine()}"
```

**示例**:
- 设备A: `24_15_AMD64` (24核CPU, 15GB内存, AMD64架构)
- 设备B: `8_8_AMD64` (8核CPU, 8GB内存, AMD64架构)
- 设备C: `4_4_ARM64` (4核CPU, 4GB内存, ARM64架构)

### 2. 设备变化检测

**检测时机**: 每次调用`get_cached_hardware()`时

**检测逻辑**:
1. 生成当前设备的硬件指纹
2. 与缓存的硬件指纹对比
3. 如果不同,说明设备发生变化,清除缓存并重新检测

**代码实现**:
```python
@classmethod
def get_cached_hardware(cls):
    """获取缓存的硬件快照（支持设备变化检测）"""
    current_time = time.time()
    
    # 生成当前硬件指纹
    try:
        import psutil
        import platform
        current_fingerprint = f"{psutil.cpu_count()}_{int(psutil.virtual_memory().total/1024**3)}_{platform.machine()}"
    except:
        current_fingerprint = "unknown"
    
    # 检查缓存是否有效
    cache_expired = (current_time - cls._cache_timestamp) > cls._cache_ttl
    hardware_changed = (cls._hardware_fingerprint != current_fingerprint)
    
    if cls._hardware_cache is None or cache_expired or hardware_changed:
        if hardware_changed:
            logger.info("🔄 检测到硬件变化，重新检测...")
        else:
            logger.info("🔄 硬件缓存过期或不存在，重新检测...")
        
        # 重新检测硬件
        detector = HardwareDetector()
        cls._hardware_cache = detector.detect_hardware()
        cls._cache_timestamp = current_time
        cls._hardware_fingerprint = current_fingerprint
        logger.info("✅ 硬件检测完成并缓存")
    else:
        logger.info("✅ 使用缓存的硬件信息")
    
    return cls._hardware_cache
```

### 3. 缓存策略

**缓存条件**:
- 硬件指纹相同
- 缓存未过期(5分钟TTL)

**缓存失效条件**:
- 硬件指纹不同(设备变化)
- 缓存过期(超过5分钟)
- 手动清除缓存

## 四、技术细节

### 1. 类级别缓存

**定义**:
```python
class UltraFastSmartDownloaderDialog(QDialog):
    # 类级别硬件缓存
    _hardware_cache = None
    _cache_timestamp = 0
    _cache_ttl = 300  # 5分钟
    _hardware_fingerprint = None  # 硬件指纹
```

**优点**:
- 所有对话框实例共享缓存
- 避免重复检测
- 提升性能

### 2. 硬件指纹对比

**对比逻辑**:
```python
hardware_changed = (cls._hardware_fingerprint != current_fingerprint)
```

**触发条件**:
- CPU核心数变化
- 系统内存总量变化
- CPU架构变化

### 3. 缓存清除

**手动清除**:
```python
UltraFastSmartDownloaderDialog.clear_cache()
```

**自动清除**:
- 检测到硬件变化时自动清除并重新检测
