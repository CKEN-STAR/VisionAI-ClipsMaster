## 📋 任务背景

用户提出两个问题：
1. GGUF格式模型的模型管理功能是否可以正常使用？
2. 转换格式时只有Q4一种量化程度吗？是项目不合适还是智能选择量化程度？

经过分析发现：
- **问题1**：GGUF模型管理功能基本正常，可以查看、删除、打开文件夹，但缺少高级功能（版本管理、性能对比）
- **问题2**：量化类型是**硬编码**的，不是智能选择。代码固定使用Q4_K_M（中文）和Q5_K（英文）

---

## 🎯 实现方案

用户选择了**方案2：智能推荐 + 手动选择**

### 核心功能

#### 1. 智能推荐系统
根据系统可用内存自动推荐最合适的量化类型：

| 可用内存 | 推荐量化类型 | 推荐理由 |
|---------|------------|---------|
| < 4GB | Q2_K | 内存较低，推荐使用极限压缩 |
| 4-8GB | Q4_K_M | 内存适中，推荐使用平衡量化 |
| 8-16GB | Q5_K | 内存充足，推荐使用高质量量化 |
| > 16GB | Q6_K | 内存充裕，推荐使用最佳质量量化 |

#### 2. 量化类型选择对话框
提供8种量化类型供用户选择：

| 量化类型 | 文件大小 | 说明 | 适用场景 |
|---------|---------|------|---------|
| Q2_K | ~0.8GB | 极限压缩，质量较低 | 内存极度受限 |
| Q4_K_S | ~1.2GB | 小体积，质量中等 | 快速测试 |
| Q4_K_M | ~1.5GB | 平衡推荐，质量良好 | 日常使用（推荐） |
| Q5_K_S | ~1.8GB | 高质量小体积 | 质量优先 |
| Q5_K | ~2.0GB | 高质量 | 生产环境 |
| Q6_K | ~2.4GB | 最佳质量 | 高质量要求 |
| Q8_0 | ~2.8GB | 高精度 | 研究用途 |
| F16 | ~3.0GB | 原始质量 | 基准测试 |

#### 3. 用户体验优化
- 显示智能推荐的量化类型和推荐理由
- 每个选项都有详细说明和预估文件大小
- 默认选中推荐的量化类型
- 用户可以自由选择或取消转换

### 核心代码

#### 智能推荐函数
```python
def recommend_quantization(model_type_str):
    """根据模型类型和系统资源智能推荐量化类型"""
    import psutil
    
    # 获取可用内存（GB）
    available_memory_gb = psutil.virtual_memory().available / (1024**3)
    
    # 根据内存推荐
    if available_memory_gb < 4:
        return "Q2_K", "内存较低，推荐使用极限压缩"
    elif available_memory_gb < 8:
        return "Q4_K_M", "内存适中，推荐使用平衡量化"
    elif available_memory_gb < 16:
        return "Q5_K", "内存充足，推荐使用高质量量化"
    else:
        return "Q6_K", "内存充裕，推荐使用最佳质量量化"
```

#### 量化类型选择对话框
```python
# 获取智能推荐
recommended_quant, recommend_reason = recommend_quantization(model_type)

# 创建选择对话框
quant_dialog = QDialog(widget)
quant_dialog.setWindowTitle("选择量化类型")
quant_dialog.setMinimumWidth(500)

# 显示推荐信息
recommend_label = QLabel(f"💡 智能推荐: {recommended_quant}\n{recommend_reason}")

# 量化类型下拉框
quant_combo = QComboBox()
quant_options = [
    ("Q2_K", "Q2_K - 极限压缩 (~0.8GB) - 质量较低，适合内存极度受限"),
    ("Q4_K_S", "Q4_K_S - 小体积 (~1.2GB) - 质量中等，适合快速测试"),
    ("Q4_K_M", "Q4_K_M - 平衡推荐 (~1.5GB) - 质量良好，适合日常使用"),
    # ... 更多选项
]

for value, text in quant_options:
    quant_combo.addItem(text, value)
    if value == recommended_quant:
        quant_combo.setCurrentIndex(quant_combo.count() - 1)
```

### 依赖库

## 🚀 使用方法

1. 打开UI，进入"设置 → 模型管理"
2. 选择一个训练模型版本
3. 点击"转换为GGUF"按钮
4. 系统会显示量化类型选择对话框
5. 查看智能推荐，选择合适的量化类型
6. 点击"确定转换"开始转换
