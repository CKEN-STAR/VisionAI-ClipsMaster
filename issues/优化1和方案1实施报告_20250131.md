## ✅ 已完成的修改

### 1. 优化1：简化Prompt + 明确数量要求

#### 1.1 修改前的Prompt（复杂版）

**问题**：
- 任务描述过于复杂（3个大点，多个子点）
- 没有明确的数量要求（只说"保留约30%-50%"）
- 输出格式要求不够明确
- 对于1.5B-1.7B的小模型来说太复杂

**原始Prompt**：
```
你是一个专业的短剧剪辑师，精通短视频平台的流量密码和用户心理。

【任务】
从第X集中提取关键对话，用于后续混剪。

【整个故事摘要】
{story_summary}

【第X集完整字幕】
{current_episode_text}

【提取要求】
1. **根据故事摘要理解当前集的作用**：
   - 识别第X集在整个故事中的位置和作用
   - 理解当前集的关键剧情点

2. **提取关键对话**：
   - 选择最精彩的对话（关键剧情、重要对话、情感高潮）
   - 删除废话、重复、过渡性对话
   - 保留约30%-50%的对话

3. **输出格式**：
   - 按照原始序号输出
   - 每行一条对话
   - 格式：序号. 对话内容

【输出示例】
1. 哪来的女王
3. 你可愿臣服于我
4. 放肆
10. 她竟是法力通天的神真女君啊
...

【开始提取】
请提取第X集的关键对话：
```

#### 1.2 修改后的Prompt（简化版）

**改进点**：
- ✅ 简化任务描述（直接说明目标）
- ✅ 明确数量要求（必须选择N条，最少M条，最多K条）
- ✅ 简化选择标准（4个简单标准）
- ✅ 明确输出格式（只输出序号，用逗号分隔）
- ✅ 提供清晰的示例

**新Prompt**：
```
你是一个专业的短剧剪辑师。

【整个故事摘要】
{story_summary}

【任务】
从第X集的{total_count}条字幕中，选择{target_count}条关键对话（最少{min_count}条，最多{max_count}条）。

【第X集完整字幕】
{current_episode_text}

【选择标准】
1. 包含重要剧情信息的对话
2. 包含情感强烈的对话
3. 包含人物关系变化的对话
4. 对话长度较长的（超过5个字）

【输出要求】
- 必须选择{target_count}条对话（最少{min_count}条，最多{max_count}条）
- 只输出序号，用逗号分隔
- 示例：1,3,4,10,15,20

【开始选择】
请选择{target_count}条关键对话的序号：
```

**数量计算逻辑**：
```python
# 计算目标数量（保留30%-50%，默认40%）
total_count = len(episode_subtitles)
target_count = int(total_count * 0.4)  # 40%
min_count = int(total_count * 0.3)  # 30%
max_count = int(total_count * 0.5)  # 50%
```

**示例**：
- 如果一集有40条字幕：
  - 目标数量：16条（40%）
  - 最少数量：12条（30%）
  - 最多数量：20条（50%）

### 2. 方案1：在关键对话提取阶段使用分析结果

#### 2.1 修改前的流程

**问题**：
- 分析结果只在步骤0（理解整个故事）中使用
- 步骤1（关键对话提取）没有使用分析结果
- 浪费了辅助模块的分析成果

**原始流程**：
```
步骤0：理解整个故事
  - 使用分析结果 ✅
  - 生成故事摘要

步骤1：逐集提取关键对话
  - 使用故事摘要 ✅
  - 不使用分析结果 ❌

步骤2：分批生成混剪SRT
  - 使用故事摘要 ✅
  - 不使用分析结果 ❌

**改进点**：

- ✅ 从节奏分析中提取建议片段
- ✅ 提供具体的选择提示

**新流程**：
```

  - 使用分析结果 ✅

### 3. 解析逻辑优化

#### 3.1 支持新的输出格式

**修改前**：
- 只支持解析 "1. 文本" 格式
- 例如：
  ```
  1. 哪来的女王
  3. 你可愿臣服于我
  4. 放肆
  ```

**修改后**：
- ✅ 优先支持逗号分隔格式（新格式）
- ✅ 回退支持 "1. 文本" 格式（旧格式）
- 例如：
  ```
  1,3,4,10,15,20
  ```

**代码实现**：
```python
# 🔧 优化1：支持新的逗号分隔格式（例如"1,3,4,10,15,20"）
key_indices = []

# 方法1：尝试解析逗号分隔的序号
for line in lines:
    # 检查是否包含逗号分隔的数字
    if ',' in line:
        # 提取所有数字
        numbers = re.findall(r'\d+', line)
        if numbers:
            key_indices.extend([int(n) for n in numbers])
            logger.info(f"第{episode_num}集：从逗号分隔格式中提取到 {len(numbers)} 个序号")
            break  # 找到逗号分隔格式后就停止

# 方法2：如果没有找到逗号分隔格式，尝试解析 "1. 文本" 格式
if not key_indices:
    for line in lines:
        # 匹配 "1. 文本" 格式
        match = re.match(r'^(\d+)\.\s+', line)
        if match:
            index = int(match.group(1))
            key_indices.append(index)
```
