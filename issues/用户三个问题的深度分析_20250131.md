### 问题分析

1. **任务描述过于复杂**：

   - 要求AI识别当前集的作用
   - 要求AI选择最精彩的对话
   - 对于1.5B模型来说太复杂

2. **输出格式要求不够明确**：
   - "保留约30%-50%的对话"太模糊
   - 没有明确的数量要求
   - 示例输出太少（只有3条）

3. **缺少具体指导**：
   - 没有告诉AI如何判断"精彩"
   - 没有提供评分标准
   - 没有提供更多示例

### 为什么辅助模块没有起到作用？

**根本原因**：
1. **分析结果只在故事理解阶段使用**
   - 在`_build_story_understanding_prompt()`中添加了分析结果
   - 但在`_build_key_dialogue_extraction_prompt()`中**没有使用**

2. **关键对话提取阶段缺少辅助信息**
   - 当前只使用了`story_summary`和`episode_subtitles`
   - 没有使用叙事分析、节奏分析、片段建议等

3. **AI模型能力不足，无法充分利用分析结果**
   - 即使添加了分析结果，1.5B模型也可能无法理解
   - 分析结果的格式可能不适合小模型

#### 方案2：使用分析结果直接生成候选序号

**更激进的方案**：不依赖AI模型，直接使用分析结果生成候选序号

```python
def _extract_key_dialogues_with_analysis(self, episode_subtitles: List[Dict[str, Any]],
                                         analysis_result: Optional[Dict[str, Any]] = None,
                                         target_ratio: float = 0.7) -> List[int]:
    """使用分析结果提取关键对话序号"""
    
    target_count = int(len(episode_subtitles) * target_ratio)
    candidate_indices = set()
    
    # 从叙事分析中提取关键情节点的序号
    if analysis_result and 'narrative' in analysis_result:
        narrative = analysis_result['narrative']
        if 'key_moments' in narrative:
            for moment in narrative['key_moments']:
                if 'subtitle_index' in moment:
                    candidate_indices.add(moment['subtitle_index'])
    
    # 从节奏分析中提取建议片段的序号
    if analysis_result and 'rhythm' in analysis_result:
        rhythm = analysis_result['rhythm']
        if 'suggested_segments' in rhythm:
            for segment in rhythm['suggested_segments']:
                start = segment.get('start_index', 0)
                end = segment.get('end_index', 0)
                candidate_indices.update(range(start, end + 1))
    
    # 如果候选序号不足，使用规则引擎补充
    if len(candidate_indices) < target_count:
        # 使用规则引擎评分，选择剩余的序号
        scored_subtitles = []
        for i, sub in enumerate(episode_subtitles):
            if i not in candidate_indices:
                score = self._calculate_subtitle_score(sub)
                scored_subtitles.append((score, i))
        
        scored_subtitles.sort(reverse=True, key=lambda x: x[0])
        needed = target_count - len(candidate_indices)
        candidate_indices.update([i for _, i in scored_subtitles[:needed]])
    
    # 如果候选序号过多，按评分排序后取前target_count个
    if len(candidate_indices) > target_count:
        scored_candidates = []
        for i in candidate_indices:
            score = self._calculate_subtitle_score(episode_subtitles[i])
            scored_candidates.append((score, i))
        
        scored_candidates.sort(reverse=True, key=lambda x: x[0])
        candidate_indices = set([i for _, i in scored_candidates[:target_count]])
    
    # 按原始顺序排序
    return sorted(list(candidate_indices))
```

**改进点**：
- ✅ 直接使用分析结果，不依赖AI模型
- ✅ 100%成功率
- ✅ 充分利用辅助模块的分析结果
- ✅ 使用规则引擎补充不足的部分

### 结论

**辅助模块确实被调用了，但没有充分发挥作用**，原因：
1. ❌ 分析结果只在故事理解阶段使用，关键对话提取阶段没有使用
2. ❌ AI模型能力不足，无法充分利用分析结果
3. ❌ 分析结果的格式可能不适合小模型

**建议**：
- ✅ 在关键对话提取阶段使用分析结果（方案1）
- ✅ 或者直接使用分析结果生成候选序号（方案2，更可靠）
