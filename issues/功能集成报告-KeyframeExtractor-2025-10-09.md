### 3. 智能方法选择

**根据视频时长自动选择最优方法**:

| 视频时长 | 提取方法 | 参数 | 说明 |
|---------|---------|------|------|
| < 5分钟 | 均匀提取 | 10帧 | 快速预览 |
| 5-30分钟 | 差异提取 | 阈值35.0 | 捕捉变化 |
| > 30分钟 | 场景变化 | 阈值30.0 | 场景分割 |

**算法**:
```python
def _select_keyframe_params(self, video_duration: float) -> tuple:
    if video_duration < 300:  # 5分钟
        return ('uniform', 10, 30.0)
    elif video_duration < 1800:  # 30分钟
        return ('difference', 20, 35.0)
    else:
        return ('scene', 30, 30.0)
```

**优点**:
- 自适应视频长度
- 无需用户配置
- 最优性能和质量平衡

### 5. 技术实现

#### 5.1 延迟导入

使用延迟导入避免cv2循环导入:
```python
from src.alignment import extract_keyframes
```

`src/alignment/__init__.py`已实现`__getattr__`延迟导入机制。

#### 5.2 错误处理

提取失败不影响后续步骤:
```python
try:
    keyframes = extract_keyframes(...)
except Exception as e:
    logger.warning(f"关键帧提取失败: {e}, 继续执行后续步骤")
    return {"keyframes": [], "keyframe_count": 0}
```

#### 5.3 数据传递

关键帧数据传递给场景分析:
```python
# 步骤4: 关键帧提取
keyframe_result = self._extract_keyframes(video_path, video_duration)

# 步骤5: 场景分析
scene_result = self._analyze_scenes(
    video_path, 
    subtitles,
    keyframe_result.get("keyframes", [])
)
```
