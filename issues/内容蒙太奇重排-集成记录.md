# 内容蒙太奇重排 - 集成记录

目的：解决混剪爆款字幕“前言不搭后语、两段交替出现”的观感问题，按参考样本实现快节奏、强跳切的蒙太奇风格（低邻接相似度，避免 A→B→A 回钩）。

## 变更摘要
- 新增引擎内部方法：RealAIEngine._arrange_for_montage(items, avoid_aba=True)
  - 采用字符3-gram Jaccard，相邻相似度最小化
  - 0.8×A-B-A 惩罚 + 0.2×同集连续惩罚
  - 去除 #ORIGINAL 元信息后进行相似度计算
- 在 generate_viral_subtitle_batch 的时间轴重建之前调用蒙太奇重排
  - 默认开启（环境变量 MONTAGE_MODE 可控制）
- 调整 _validate_batch_coherence：
  - 蒙太奇模式下：低重叠（<0.1）加分（而非减分）；大集数跨度不再扣分

## 关键插入点
- src/core/real_ai_engine.py
  - after: “总共生成 X 条混剪字幕” → 调用 `_arrange_for_montage(...)`
  - new: `_arrange_for_montage(...)` 方法定义（在 `_regenerate_timeline` 之前）
  - change: `_validate_batch_coherence(...)` 针对 montage 模式的评分调整

## 开关控制
- 环境变量：MONTAGE_MODE（默认开启）
  - '1'/'true'/'yes'/'on' → 启用
  - 其它 → 禁用
