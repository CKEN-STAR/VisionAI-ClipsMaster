# P1：评估闭环 + 数据增强质量阈值 + 内存微调（执行记录）

## 背景
- 已完成 P0：动态评估策略（按有无验证集启用）、动态日志/评估步频、训练指标落盘。
- 本轮目标（P1）：
  1) 有验证集即启用评估与早停（无验证集则自动划分 80/20）
  2) 训练数据增强阶段接入“Step7 质量评分阈值”过滤
  3) 降低训练时内存压力（max_length 2048→1536）

## 变更清单
- src/training/model_fine_tuner.py
  - default_config.training.max_length: 2048 → 1536
  - data_augmentation 增加字段 reconstruction_quality_threshold=5.5（保留 legacy 字段 quality_threshold 兼容）
  - _load_training_data:
    - 创建 ReconstructionAugmenter 后注入质量阈值（支持 0~1 或 0~10 配置）
    - 如无外部验证集，且样本量≥10，自动 80/20 划分验证集并记录日志
- src/training/reconstruction_augmenter.py
  - augment_sample:
    - 调用 engineer._calculate_reconstruction_quality() 计算 Step7 评分（0~10）
    - 同时执行基础校验 + 阈值过滤；不达标的变体丢弃并记警告
    - 通过的变体写入 quality_score 字段

## 预期效果
- 有验证集时：
  - eval_strategy=steps 生效、EarlyStoppingCallback 启用、load_best_model_at_end=True
  - 输出 eval_results.json
- 无验证集时：
  - 自动划分验证集（约 20%），训练与评估闭环生效
- 训练数据增强：
  - 低于阈值（默认 5.5/10）的重构变体不进入训练集，整体样本质量提升
- 内存压力：
  - max_length 1536 期望较 2048 有明显下降（仍保留 16-bit/LoRA/GC 优化）

## 运行与验证计划
1) 编译检查（py_compile）
2) 小规模复跑（1~2 epoch，保留自动划分验证集）：
   - 观察 eval 频率、早停是否触发、eval_results.json 产出
   - 记录 train_loss、eval_loss、best_checkpoint
   - 统计增强阶段“变体通过/丢弃”数量

## 备注
- reconstruction_quality_threshold 可在配置中快速调参（如 5.5→6.0）
- 若对总样本量敏感，可临时将 split_ratio 从 0.2 调低到 0.1
