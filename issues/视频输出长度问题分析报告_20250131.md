## 💡 解决方案

### 方案A：使用规则引擎替代AI提取关键对话（推荐）

**原理**：
- 不依赖AI模型提取关键对话
- 使用确定性的规则和算法
- 确保提取到足够数量的关键对话

**实施步骤**：

1. **添加规则引擎方法** `_extract_key_dialogues_by_rules()`:
   ```python
   def _extract_key_dialogues_by_rules(self, episode_subtitles: List[Dict[str, Any]], 
                                       target_ratio: float = 0.7) -> List[Dict[str, Any]]:
       """
       使用规则引擎提取关键对话
       
       Args:
           episode_subtitles: 当前集的字幕列表
           target_ratio: 目标保留比例（默认70%）
       
       Returns:
           关键对话列表
       """
       # 计算目标数量
       target_count = int(len(episode_subtitles) * target_ratio)
       
       # 评分规则：
       # 1. 字幕长度（越长越重要）
       # 2. 包含关键词（人名、地名、情感词等）
       # 3. 位置权重（开头和结尾更重要）
       
       scored_subtitles = []
       for i, sub in enumerate(episode_subtitles):
           score = 0
           text = sub.get('text', '')
           
           # 长度权重（40%）
           length_score = min(len(text) / 50, 1.0)  # 最多50字
           score += length_score * 0.4
           
           # 关键词权重（40%）
           keyword_score = self._calculate_keyword_score(text)
           score += keyword_score * 0.4
           
           # 位置权重（20%）
           position_score = 1.0 if i < 5 or i >= len(episode_subtitles) - 5 else 0.5
           score += position_score * 0.2
           
           scored_subtitles.append((score, i, sub))
       
       # 按分数排序，取前target_count个
       scored_subtitles.sort(reverse=True, key=lambda x: x[0])
       selected = scored_subtitles[:target_count]
       
       # 按原始顺序排序
       selected.sort(key=lambda x: x[1])
       
       # 返回字幕列表
       return [sub for _, _, sub in selected]
   ```

2. **修改关键对话提取逻辑**:

**优点**：
