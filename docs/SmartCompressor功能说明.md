# SmartCompressor (智能自适应压缩器) 功能说明

## 一、功能概述

**SmartCompressor** 是一个智能压缩器,可以根据系统内存状态自动调整压缩参数,实现内存压力与性能的平衡。

### 核心价值

- 🧠 **智能化**: 自动监控内存,无需手动干预
- 💾 **节省内存**: 内存紧张时自动提高压缩率
- ⚡ **提升性能**: 内存充足时降低压缩率,提升速度
- 🛡️ **稳定性**: 防止内存溢出导致程序崩溃

---

## 二、工作原理

### 2.1 内存监控

SmartCompressor会持续监控系统内存使用情况,并评估内存压力级别:

| 内存使用率 | 压力级别 | 说明 |
|-----------|---------|------|
| < 50% | 低压力 (LOW) | 内存充足,可以使用低压缩率 |
| 50-70% | 中等压力 (MEDIUM) | 内存适中,使用平衡的压缩率 |
| 70-85% | 高压力 (HIGH) | 内存紧张,需要提高压缩率 |
| > 85% | 临界压力 (CRITICAL) | 内存不足,使用最高压缩率 |

### 2.2 动态调整策略

根据内存压力级别和资源优先级,自动调整压缩参数:

#### 压缩级别 (1-9)
- **级别1**: 最快速度,最低压缩率
- **级别5**: 平衡速度和压缩率
- **级别9**: 最高压缩率,最慢速度

#### 压缩算法
- **LZ4**: 最快速度,适合高优先级资源
- **ZSTD**: 平衡速度和压缩率,适合中等优先级
- **BZIP2**: 高压缩率,适合低优先级资源
- **LZMA**: 最高压缩率,适合内存临界状态

### 2.3 资源优先级

SmartCompressor支持三种资源优先级:

#### 高优先级资源 (HIGH)
- **特点**: 需要快速访问,速度优先
- **示例**: 正在编辑的视频片段、实时预览数据
- **策略**: 使用低压缩率(LZ4算法,级别1-3)

#### 中等优先级资源 (MEDIUM)
- **特点**: 平衡速度和内存占用
- **示例**: 已加载的视频文件、字幕数据
- **策略**: 使用平衡压缩(ZSTD算法,级别1-5)

#### 低优先级资源 (LOW)
- **特点**: 不常访问,可以牺牲速度节省内存
- **示例**: 缓存数据、临时文件
- **策略**: 使用高压缩率(BZIP2/LZMA算法,级别3-9)

## 四、硬件加速

SmartCompressor支持GPU硬件加速:

- ✅ **NVIDIA GPU**: 使用CUDA加速压缩/解压
- ✅ **自动检测**: 自动检测可用的GPU硬件
- ✅ **自动切换**: GPU不可用时自动切换到CPU

### 性能提升

- **压缩速度**: 提升2-5倍
- **解压速度**: 提升3-8倍
- **CPU占用**: 降低50-80%

---

## 五、统计信息

SmartCompressor会记录以下统计信息:

| 统计项 | 说明 |
|-------|------|
| level_adjustments | 压缩级别调整次数 |
| algo_switches | 压缩算法切换次数 |
| compression_count | 压缩操作次数 |
| decompression_count | 解压操作次数 |
| bytes_processed | 处理的总字节数 |
| bytes_output | 输出的总字节数 |
| average_ratio | 平均压缩率 |
| time_spent | 总耗时(秒) |
| memory_samples | 内存采样历史 |

## 六、使用场景

### 场景1: 处理大视频文件
- **问题**: 加载多个大视频文件导致内存不足
- **解决**: SmartCompressor自动提高压缩率,节省内存
- **效果**: 可以同时处理更多视频文件

### 场景2: 低配置电脑
- **问题**: 8GB内存的电脑处理4K视频卡顿
- **解决**: SmartCompressor自动使用高压缩率
- **效果**: 降低内存占用,提升稳定性

### 场景3: 高配置电脑
- **问题**: 32GB内存的电脑压缩太慢
- **解决**: SmartCompressor检测到内存充足,使用低压缩率
- **效果**: 提升处理速度,充分利用硬件

### 方案2: 工具菜单 + 对话框

**位置**: 工具菜单 → "压缩设置"

**UI控件**:
- 菜单项: "压缩设置"
- 对话框显示:
  - 当前内存压力级别
  - 当前压缩算法和级别

**优点**:
- ✅ 提供详细的统计信息
- ✅ 高级用户可以调整参数

**缺点**:
- ⚠️ 需要创建新的对话框
- ⚠️ 对普通用户可能过于复杂

**实现方式**:

**优点**:
