## 🔧 **技术细节**

### GPTQ + LoRA的工作原理

1. **GPTQ量化模型**:
   - 基础模型参数被量化为INT4
   - 参数是离散整数,无法计算梯度
   - 参数被冻结,不参与训练

2. **LoRA适配器**:
   - 在冻结的基础模型上添加小型适配器
   - 适配器参数是FP16/BF16,可以计算梯度
   - 只训练适配器参数(4.3M)

3. **训练过程**:
   - 前向传播: 基础模型(冻结) + LoRA适配器(可训练)
   - 反向传播: 只更新LoRA适配器的参数
   - 保存: 只保存LoRA适配器权重(小文件)

### 为什么这次成功了?

**关键修复**:
```python
# 使用prepare_model_for_kbit_training准备模型
from peft import prepare_model_for_kbit_training
model = prepare_model_for_kbit_training(model)
```

**这个函数的作用**:
1. 冻结基础模型的所有参数
2. 启用梯度检查点(节省显存)
3. 将输入嵌入层转换为FP32(提高精度)
4. 准备模型用于PEFT(LoRA)训练
