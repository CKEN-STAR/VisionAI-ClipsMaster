## 📊 项目概况

### 基本信息
- **项目名称**：VisionAI-ClipsMaster
- **项目类型**：AI驱动的短剧视频混剪工具
- **开发语言**：Python 3.11+
- **主要框架**：PyQt6, FFmpeg, llama-cpp-python, PyTorch
- **AI模型**：Mistral系列 (英文) + Qwen2.5系列 (中文，智能推荐0.5B/1.5B/3B/7B/14B/32B)

### 项目规模
- **代码行数**：约15,000行
- **文件数量**：约200个文件
- **项目体积**：1.46GB（优化后）
- **测试覆盖率**：100%（核心功能）
