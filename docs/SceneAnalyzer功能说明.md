# SceneAnalyzer功能说明

## 功能概述

**SceneAnalyzer**(场景分析器)是一个智能视频场景检测和分析系统。它可以自动识别视频中的场景变化,分析每个场景的特征,并将场景与字幕内容关联起来。

### 核心特性

1. **自动场景检测**: 基于帧差异算法自动检测视频中的场景变化点
2. **场景分类**: 智能分类场景类型(日景/夜景/室内/室外)
3. **关键帧提取**: 为每个场景提取代表性关键帧
4. **字幕关联**: 将字幕数据自动关联到对应的场景
5. **元数据分析**: 分析场景的亮度、颜色分布等视觉特征

## 工作原理

### 1. 场景检测算法

SceneAnalyzer使用**帧差异检测算法**来识别场景变化:

```
1. 读取视频的每一帧
2. 计算相邻帧之间的差异(灰度差异)
3. 当差异超过阈值时,认为发生了场景切换
4. 记录场景切换的时间点
5. 生成场景列表
```

**参数**:
- `scene_threshold`: 场景变化阈值(默认30.0),值越小越敏感
- `min_scene_duration`: 最小场景持续时间(默认1.0秒)

### 2. 场景分类

每个检测到的场景会被自动分类:

#### 日夜分类

| 类型 | 判断标准 | 说明 |
|------|---------|------|
| **night** | 平均亮度 < 80 | 夜景,画面较暗 |
| **indoor** | 80 ≤ 平均亮度 < 160 | 室内场景,中等亮度 |
| **day** | 平均亮度 ≥ 160 | 日景,画面明亮 |

#### 室内外分类

| 类型 | 判断标准 | 说明 |
|------|---------|------|
| **outdoor** | 非夜景 且 饱和度 > 100 | 室外场景,色彩饱和度高 |
| **indoor** | 其他情况 | 室内场景,色彩饱和度低 |

### 3. 关键帧提取

为每个场景提取代表性关键帧:
- 场景开始帧
- 场景中间帧
- 场景结束帧

### 4. 元数据分析

为每个场景生成详细的元数据:
- **brightness**: 平均亮度值(0-255)
- **color_histogram**: 颜色直方图
- **confidence**: 分类置信度(0-1)
- **scene_type**: 场景类型(night/indoor/day)
- **location**: 位置类型(indoor/outdoor)

## 使用场景

### 场景1: 视频内容分析

**需求**: 了解视频的场景构成

**操作流程**:
1. 打开VisionAI-ClipsMaster
2. 点击"工具"菜单 → "场景分析"(或按Ctrl+S)
3. 点击"浏览..."选择视频文件
4. 点击"开始分析"
5. 查看场景列表和统计信息

**输出结果**:
```
场景数量: 15
场景类型统计:
  day: 8
  indoor: 5
  night: 2
```

**用户价值**:
- 快速了解视频的场景构成
- 识别视频的拍摄环境(室内/室外)
- 分析视频的时间分布(日景/夜景)

### 场景2: 辅助剪辑决策

**需求**: 选择重要场景进行剪辑

**操作流程**:
1. 分析视频场景
2. 查看场景列表,找到关键场景
3. 记录场景的时间范围
4. 在剪辑时重点处理这些场景

**示例**:
```
场景 3:
  时间范围: 15.50s - 28.30s
  持续时间: 12.80s
  场景类型: day
  位置: outdoor
  置信度: 0.85
```

**用户价值**:
- 快速定位重要场景
- 避免遗漏关键内容
- 提高剪辑效率

### 场景3: 字幕与场景关联

**需求**: 了解每个场景对应的字幕内容

**操作流程**:
1. 准备视频文件和SRT字幕文件
2. 分析视频场景(自动关联字幕)
3. 查看每个场景的字幕内容

**输出结果**:
```
场景 5:
  时间范围: 45.20s - 58.60s
  字幕内容: "这是一个重要的转折点..."
  场景类型: indoor
```

**用户价值**:
- 理解场景的叙事内容
- 辅助剧情分析
- 优化字幕时间轴

### 场景4: 导出场景数据

**需求**: 保存场景分析结果供后续使用

**操作流程**:
1. 完成场景分析
2. 点击"导出JSON"或"导出报告"
3. 选择保存位置
4. 保存场景数据

**JSON格式示例**:
```json
[
  {
    "scene_id": 1,
    "start_time": 0.0,
    "end_time": 12.5,
    "duration": 12.5,
    "scene_type": "day",
    "location": "outdoor",
    "confidence": 0.85,
    "text": "开场白...",
    "metadata": {
      "brightness": 180.5,
      "color_histogram": [...]
    }
  }
]
```

**用户价值**:
- 保存分析结果
- 与其他工具集成
- 批量处理多个视频

## 技术细节

### 依赖模块

- `cv2` (OpenCV): 视频处理和帧差异计算
- `numpy`: 数值计算
- `src.alignment.keyframe_extractor`: 关键帧提取
- `src.utils.log_handler`: 日志记录

### 性能优化

1. **延迟导入**: cv2和numpy采用延迟导入,避免启动时的循环导入问题
2. **帧采样**: 不是每一帧都计算差异,而是按一定间隔采样
3. **阈值过滤**: 只有差异超过阈值的才记录为场景变化
4. **最小持续时间**: 过滤掉过短的场景,避免误检

### 配置参数

可以通过修改SceneAnalyzer的初始化参数来调整检测行为:

```python
analyzer = SceneAnalyzer(
    min_scene_duration=1.0,      # 最小场景持续时间(秒)
    scene_threshold=30.0,        # 场景变化阈值
    use_external_models=False    # 是否使用外部深度学习模型
)
```

## 常见问题

### Q1: 为什么有些场景没有被检测到?

**A**: 可能是因为:
1. 场景变化不明显,差异小于阈值
2. 场景持续时间太短,被过滤掉了

**解决方法**:
- 降低`scene_threshold`参数(如改为20.0)
- 降低`min_scene_duration`参数(如改为0.5秒)

### Q2: 为什么有些场景被错误分类?

**A**: 场景分类基于简单的亮度和饱和度规则,可能不够准确。

**解决方法**:
- 使用外部深度学习模型(设置`use_external_models=True`)
- 手动调整分类结果

### Q3: 分析大视频文件很慢怎么办?

**A**: 场景分析需要读取整个视频,大文件会比较慢。

**优化建议**:
- 使用SSD硬盘存储视频
- 降低视频分辨率
- 增加帧采样间隔

### Q4: 导出的JSON文件如何使用?

**A**: JSON文件可以:
1. 导入到其他视频编辑软件
2. 用于批量处理脚本
3. 与MetaClipEngine集成使用

## 与其他功能的集成

### 与MetaClipEngine集成

场景分析结果可以直接用于MetaClipEngine:

```python
# 1. 分析场景
scenes = analyzer.analyze_video("video.mp4")

# 2. 为每个场景创建MetaClip
for scene in scenes:
    meta_clip = MetaClip(
        operation="slice",
        src="video.mp4",
        in_point=scene.start_time,
        out_point=scene.end_time,
        codec="copy"
    )
```

```

5. 剧本重构
6. 视频生成
7. 导出工程
```
