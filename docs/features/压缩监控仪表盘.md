# 压缩监控仪表盘 (CompressionDashboard)

## 功能概述

压缩监控仪表盘是一个可视化性能监控工具，实时显示压缩系统的性能指标，包括压缩率、吞吐量、资源使用情况和算法对比。

## 功能特性

### 1. 实时监控
- **压缩率仪表盘**: 以仪表盘形式显示当前压缩率
- **吞吐量图表**: 实时折线图显示压缩吞吐量变化
- **算法对比**: 表格形式对比不同压缩算法的性能
- **内存监控**: 实时显示内存使用情况

### 2. 历史趋势分析
- **历史压缩率图表**: 显示长期压缩率变化趋势（最多1000个数据点）
- **历史吞吐量图表**: 显示长期吞吐量变化趋势（最多1000个数据点）
- **趋势分析**: 帮助识别性能瓶颈和优化机会

### 3. 详细统计信息
- 压缩操作次数
- 解压操作次数
- 处理的总字节数
- 输出的总字节数
- 平均压缩率
- 总耗时
- 平均吞吐量
- 算法切换次数
- 当前内存压力级别
- 压缩级别调整次数

### 4. 基准测试
- 一键运行压缩算法基准测试
- 对比不同算法的性能表现
- 测试指标包括：
  - 压缩率
  - 压缩速度
  - 解压速度
  - 内存使用

### 5. 可配置更新频率
支持多种更新频率：
- 1秒（高频监控）
- 2秒（默认）
- 5秒（中频监控）
- 10秒（低频监控）

## 使用方法

### 启动仪表盘

#### 方法1: 通过菜单
1. 打开主界面
2. 点击"工具"菜单
3. 选择"压缩性能监控"

#### 方法2: 通过代码
```python
from src.ui.compression_dashboard import get_compression_dashboard_launcher

# 获取启动器
launcher = get_compression_dashboard_launcher()

# 启动仪表盘
launcher.launch_dashboard()
```

#### 方法3: 独立运行
```bash
python src/ui/compression_dashboard.py
```

### 查看实时监控

1. 打开仪表盘后，默认显示"实时监控"标签页
2. 观察以下指标：
   - **左上角**: 压缩率仪表盘（0-100%）
   - **右上角**: 吞吐量折线图（MB/s）
   - **左下角**: 算法对比表格
   - **右下角**: 内存使用监控

### 查看历史趋势

1. 点击"历史趋势"标签页
2. 查看两个图表：
   - **上方**: 历史压缩率变化
   - **下方**: 历史吞吐量变化
3. 图表自动保存最近1000个数据点

### 查看详细统计

1. 点击"详细信息"标签页
2. 查看完整的统计信息表格
3. 所有指标实时更新

### 运行基准测试

1. 点击右上角"运行基准测试"按钮
2. 等待测试完成（约10-30秒）
3. 查看"实时监控"页面的算法对比表格
4. 对比结果包括：
   - 各算法的压缩率
   - 压缩速度（MB/s）
   - 解压速度（MB/s）
   - 内存使用（MB）

### 调整更新频率

1. 在顶部选择"更新频率"下拉框
2. 选择合适的更新间隔：
   - **1秒**: 适合调试和快速变化场景
   - **2秒**: 默认设置，平衡性能和实时性
   - **5秒**: 适合长期监控
   - **10秒**: 适合低资源消耗场景

## 参数说明

| title | str | "吞吐量" | 图表标题 |
| unit | str | "MB/s" | 单位 |

### 更新频率选项

| 选项 | 间隔（毫秒） | 适用场景 |
|------|-------------|----------|
| 1秒 | 1000 | 调试、快速变化 |
| 2秒 | 2000 | 默认、平衡 |

| 10秒 | 10000 | 低资源消耗 |

## 注意事项

### 1. 性能影响
- 更新频率越高，CPU使用率越高
- 建议在性能敏感场景使用5秒或10秒更新频率
- 基准测试会占用较多CPU资源，避免在关键任务期间运行

### 2. 数据准确性
- 压缩率和吞吐量基于实际压缩操作统计
- 如果没有压缩操作，数据可能为0或不更新
- 基准测试使用50MB测试数据，结果仅供参考

### 3. 内存使用
- 历史数据保存在内存中
- 每个图表最多保存1000个数据点
- 长时间运行不会导致内存泄漏

### 4. 线程安全
- 仪表盘在主线程中运行
- 基准测试在独立线程中运行
- 关闭窗口会自动停止所有监控和测试

### 5. 依赖要求
- **必需**: PyQt6, psutil
- **可选**: pyqtgraph（用于高级图表，当前未使用）
- **必需模块**: 
  - `src.compression.adaptive_compression`
  - `src.compression.hardware_accel`
  - `src.compression.core`
  - `src.ui.components.memory_visualization`

## 限制

1. **单实例**: 同时只能打开一个仪表盘窗口
2. **数据持久化**: 历史数据不会保存到磁盘，关闭窗口后丢失
3. **算法限制**: 基准测试跳过极慢的算法（lzma, xz）
4. **测试数据**: 基准测试使用固定的50MB测试数据
5. **图表类型**: 当前使用自定义绘制，未使用pyqtgraph高级功能

## 故障排除

### 问题1: 仪表盘无数据显示
**原因**: 没有压缩操作发生  
**解决**: 执行一些压缩操作，或运行基准测试

### 问题2: 基准测试失败
**原因**: 缺少依赖或算法不可用  
**解决**: 检查压缩模块是否正确安装

### 问题3: 内存监控不工作
**原因**: MemoryWidget组件未正确初始化  
**解决**: 检查 `src.ui.components.memory_visualization` 模块

### 问题4: 更新频率无效
**原因**: 计时器未正确启动  
**解决**: 重启仪表盘或检查日志
