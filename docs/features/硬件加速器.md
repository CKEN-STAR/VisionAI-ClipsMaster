# 硬件加速器 (HardwareAccelerator)

## 功能概述

硬件加速器是VisionAI-ClipsMaster的核心性能优化模块，提供GPU/CPU压缩加速能力，自动选择最佳硬件设备以提升数据压缩和处理性能。

## 核心功能

### 1. 多硬件支持

- **CUDA GPU加速**：利用NVIDIA GPU加速压缩/解压过程
- **Intel QAT加速**：支持Intel QuickAssist Technology硬件加速
- **CPU优化**：多核CPU并行压缩
- **智能回退**：硬件不可用时自动回退到CPU模式

### 2. 自动硬件选择

系统会自动检测可用硬件并选择性能最佳的设备：

1. 优先使用CUDA GPU（如果可用）
2. 其次使用Intel QAT（如果可用）
3. 最后回退到CPU多核并行

### 3. 性能优化

- **零拷贝传输**：减少内存拷贝开销
- **批量处理**：批量压缩多个数据块
- **异步处理**：异步压缩/解压，不阻塞主线程
- **内存池**：复用内存缓冲区，减少分配开销

## 配置选项

### 压缩算法

支持的压缩算法：
- `zstd`（推荐）：高压缩比，高速度
- `lz4`：超高速度，中等压缩比
- `gzip`：兼容性好，中等速度
- `brotli`：最高压缩比，较慢速度

### 压缩级别

- **级别1-3**：快速压缩，低压缩比
- **级别4-6**：平衡模式（推荐）
- **级别7-9**：高压缩比，较慢速度

## 故障排除

### 问题1：CUDA不可用

**症状**：日志显示"CUDA不可用"

**解决方案**：
1. 检查是否安装了PyTorch：`pip install torch`
2. 检查CUDA驱动是否正确安装
3. 检查GPU是否被其他程序占用

### 问题2：内存不足

**症状**：压缩大文件时内存溢出

**解决方案**：
1. 使用分块压缩：`compressor.compress_chunked(data, chunk_size=10*1024*1024)`
2. 降低压缩级别：`level=1`
3. 使用CPU压缩器：`use_cuda=False`

### 问题3：性能不佳

**症状**：GPU压缩速度不如预期

**解决方案**：
1. 检查GPU显存是否充足
2. 增大批量大小：`batch_size=64`
3. 使用更快的压缩算法：`algorithm='lz4'`

## 最佳实践

### 1. 选择合适的压缩算法

- **视频数据**：使用`zstd`，级别3-5
- **文本数据**：使用`brotli`，级别6-8
- **实时处理**：使用`lz4`，级别1-3

### 2. 优化内存使用

```python
# 使用分块压缩处理大文件
compressor = get_best_hardware()
compressed_chunks = []

for chunk in data_chunks:
    compressed, _ = compressor.compress(chunk)
    compressed_chunks.append(compressed)
```

### 3. 监控性能

```python
import time

start = time.time()
compressed, metadata = compressor.compress(data)
elapsed = time.time() - start

throughput = len(data) / elapsed / 1024 / 1024  # MB/s
print(f"压缩速度: {throughput:.2f} MB/s")
```
