# 错误可视化对话框 (ErrorVisualizationDialog)

## 功能概述

错误可视化对话框是一个增强的错误显示系统，提供比标准错误消息框更详细、更友好的错误信息展示。

## 功能特性

### 1. 错误类型分类
支持多种错误类型的分类显示：
- **系统错误** (SYSTEM): 系统级别的错误
- **用户错误** (USER): 用户操作导致的错误
- **网络错误** (NETWORK): 网络连接相关错误
- **文件错误** (FILE): 文件操作相关错误
- **内存错误** (MEMORY): 内存不足或内存相关错误
- **权限错误** (PERMISSION): 权限不足错误
- **验证错误** (VALIDATION): 输入验证失败错误
- **未知错误** (UNKNOWN): 未分类的错误

### 2. 详细错误信息
每个错误可以包含：
- **错误消息**: 简短的错误描述
- **错误类型**: 错误的分类
- **时间戳**: 错误发生的时间
- **详细信息**: 更详细的错误说明
- **建议解决方案**: 针对性的解决建议列表
- **堆栈跟踪**: 技术人员调试用的堆栈信息

### 3. 错误历史记录
- 自动记录最近100个错误
- 支持查看错误历史
- 提供错误统计功能

### 4. 便捷函数
提供多种便捷函数快速显示不同类型的错误：
- `show_simple_error()`: 显示简单错误
- `show_system_error()`: 显示系统错误
- `show_user_error()`: 显示用户错误
- `show_file_error()`: 显示文件错误

## 使用方法

### 基础用法

```python
from ui.feedback.error_visualizer import ErrorVisualizer, ErrorInfo, ErrorType

# 创建错误可视化器
visualizer = ErrorVisualizer(parent=self)

# 显示简单错误
visualizer.show_simple_error("操作失败", ErrorType.USER)

# 显示详细错误
error_info = ErrorInfo(
    message="无法加载模型",
    error_type=ErrorType.FILE,
    details="模型文件不存在或已损坏",
    suggestions=[
        "检查模型文件是否存在",
        "重新下载模型",
        "检查文件权限"
    ]
)
visualizer.show_error(error_info)
```

### 快捷函数用法

```python
from ui.feedback.error_visualizer import show_error, ErrorType

# 快速显示错误
show_error("网络连接失败", ErrorType.NETWORK, parent=self)
```

### 显示系统错误

```python
visualizer.show_system_error(
    message="内存不足",
    details="可用内存: 512MB, 需要: 2GB"
)
```

### 显示用户错误

```python
visualizer.show_user_error(
    message="输入格式不正确",
    suggestions=[
        "请输入有效的文件路径",
        "文件路径不能包含特殊字符"
    ]
)
```

### 显示文件错误

```python
visualizer.show_file_error(
    message="无法读取文件",
    file_path="/path/to/file.txt"
)
```

### 查看错误历史

```python
# 获取错误历史
history = visualizer.get_error_history()
for error in history:
    print(f"{error.timestamp}: {error.message}")

# 获取错误统计
stats = visualizer.get_error_statistics()
print(f"系统错误: {stats.get('system', 0)}次")
print(f"用户错误: {stats.get('user', 0)}次")

# 清除错误历史
visualizer.clear_error_history()
```

## 参数说明

### ErrorInfo 数据类

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| message | str | 是 | 错误消息 |
| error_type | ErrorType | 是 | 错误类型 |
| details | str | 否 | 详细信息 |
| suggestions | List[str] | 否 | 解决建议列表 |
| timestamp | str | 否 | 时间戳（自动生成） |
| traceback | str | 否 | 堆栈跟踪信息 |

### ErrorType 枚举

| 值 | 说明 |
|------|------|
| SYSTEM | 系统错误 |
| USER | 用户错误 |
| NETWORK | 网络错误 |
| FILE | 文件错误 |
| MEMORY | 内存错误 |
| PERMISSION | 权限错误 |
| VALIDATION | 验证错误 |
| UNKNOWN | 未知错误 |

## 注意事项

### 1. 错误历史限制
- 默认保存最近100个错误
- 超过限制会自动删除最早的错误
- 可通过 `max_history` 参数调整

### 2. 性能考虑
- 错误历史存储在内存中
- 长时间运行可能积累大量错误记录
- 建议定期清理错误历史

### 3. 线程安全
- 错误显示必须在主线程中调用
- 从工作线程显示错误需要使用信号槽机制

### 4. 父组件
- 建议提供父组件以正确定位对话框
- 无父组件时对话框会居中显示

## 集成建议

### 1. 全局错误处理
可以在应用程序的全局异常处理器中使用：

```python
import sys
from ui.feedback.error_visualizer import ErrorVisualizer, ErrorInfo, ErrorType

class Application:
    def __init__(self):
        self.error_visualizer = ErrorVisualizer()
        sys.excepthook = self.handle_exception
    
    def handle_exception(self, exc_type, exc_value, exc_traceback):
        import traceback
        error_info = ErrorInfo(
            message=str(exc_value),
            error_type=ErrorType.SYSTEM,
            details=f"异常类型: {exc_type.__name__}",
            traceback=''.join(traceback.format_tb(exc_traceback))
        )
        self.error_visualizer.show_error(error_info)
```

### 2. 替换现有错误处理
逐步替换项目中的 `QMessageBox.critical()` 调用：

```python
# 旧代码
QMessageBox.critical(self, "错误", "操作失败")

# 新代码
from ui.feedback.error_visualizer import show_error, ErrorType
show_error("操作失败", ErrorType.USER, parent=self)
```

### 3. 与日志系统集成
可以与日志系统结合使用：

```python
import logging
from ui.feedback.error_visualizer import ErrorVisualizer, ErrorInfo, ErrorType

logger = logging.getLogger(__name__)
visualizer = ErrorVisualizer()

try:
    # 某些操作
    pass
except Exception as e:
    logger.error(f"操作失败: {e}", exc_info=True)
    error_info = ErrorInfo(
        message="操作失败",
        error_type=ErrorType.SYSTEM,
        details=str(e)
    )
    visualizer.show_error(error_info)
```

## 限制

1. **UI线程限制**: 必须在主UI线程中调用
2. **模态对话框**: 错误对话框是模态的，会阻塞用户操作
3. **历史记录**: 仅在内存中保存，应用重启后丢失
4. **国际化**: 当前仅支持中文界面
