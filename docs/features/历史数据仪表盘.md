# 历史数据仪表盘 (HistoryDashboard)

## 功能概述

历史数据仪表盘是一个专业的性能分析工具，提供历史性能数据的可视化展示，包括内存使用趋势、缓存性能分析和OOM风险评估。

## 功能特性

### 1. 内存使用趋势分析
- **历史数据可视化**: 显示指定天数内的内存使用趋势
- **峰值和平均值**: 同时显示峰值内存使用率和平均内存使用率
- **趋势预测**: 基于历史数据预测未来30天的内存使用情况
- **趋势类型识别**: 自动识别内存使用趋势（显著上升、缓慢上升、稳定、缓慢下降、显著下降）

### 2. 缓存性能分析
- **缓存命中率趋势**: 显示历史缓存命中率变化
- **缓存健康评分**: 综合评估缓存性能（优秀、良好、一般、较差、很差）
- **性能指标**: 平均命中率、驱逐率等关键指标
- **优化建议**: 基于缓存性能提供针对性优化建议

### 3. OOM风险评估
- **风险等级**: 评估OOM（内存溢出）风险等级（低、中、中高、高）
- **历史预警统计**: 统计历史警告、错误和严重预警次数
- **风险预测**: 基于历史数据预测未来OOM风险
- **详细分析**: 提供风险原因和具体建议

### 4. 报告生成
- **日报生成**: 一键生成每日性能报告
- **周报生成**: 一键生成每周性能报告
- **报告查看**: 查看历史生成的报告
- **报告列表**: 显示最近5份报告

### 5. 系统优化建议
- **内存优化建议**: 基于内存使用趋势提供优化建议
- **缓存优化建议**: 基于缓存性能提供优化建议
- **OOM风险建议**: 基于OOM风险评估提供预防建议
- **综合建议**: 提供系统配置和优化的综合建议

### 6. 可配置分析周期
支持多种分析周期：
- 1天（短期分析）
- 3天（近期分析）
- 7天（默认，周分析）
- 14天（双周分析）
- 30天（月分析）

## 使用方法

### 启动仪表盘

#### 方法1: 通过菜单
1. 打开主界面
2. 点击"查看"菜单
3. 选择"历史数据分析"

#### 方法2: 通过代码
```python
from src.ui.history_dashboard import HistoryDashboard

# 创建仪表盘
dashboard = HistoryDashboard()
dashboard.show()
```

#### 方法3: 独立运行
```bash
python src/ui/history_dashboard.py
```

### 查看内存趋势

1. 打开仪表盘后，左侧上方显示"内存使用趋势"图表
2. 图表显示两条曲线：
   - **红色曲线**: 峰值内存使用率
   - **蓝色曲线**: 平均内存使用率
3. X轴显示日期，Y轴显示内存使用率（%）
4. 鼠标悬停可查看具体数值

### 查看缓存性能

1. 左侧下方显示"缓存命中率趋势"图表
2. 图表显示绿色曲线：缓存命中率
3. X轴显示日期，Y轴显示命中率（%）
4. 命中率越高，缓存性能越好

### 查看报告摘要

右侧上方显示"报告摘要"，包括：

| 指标 | 说明 |
|------|------|
| 峰值内存使用率 | 分析周期内的最高内存使用率 |
| 平均内存使用率 | 分析周期内的平均内存使用率 |
| 峰值进程内存 | 分析周期内进程占用的最大内存（MB） |
| 平均进程内存 | 分析周期内进程占用的平均内存（MB） |
| 缓存命中率 | 分析周期内的平均缓存命中率 |
| 内存使用趋势 | 趋势类型（显著上升/缓慢上升/稳定/缓慢下降/显著下降） |
| 缓存健康状态 | 缓存性能评级（优秀/良好/一般/较差/很差） |
| OOM风险等级 | OOM风险评估（低/中/中高/高） |

### 查看优化建议

右侧下方显示"系统优化建议"，包括：

1. **内存使用建议**
   - 根据内存趋势提供针对性建议
   - 警告潜在的内存泄漏风险
   - 建议内存配置优化

2. **缓存性能建议**
   - 根据缓存健康评分提供优化建议
   - 建议缓存策略调整
   - 提示缓存大小优化

3. **OOM风险建议**
   - 根据风险等级提供预防措施
   - 详细分析风险原因
   - 提供具体的解决方案

4. **综合建议**
   - 系统配置建议
   - 资源优化建议
   - 长期运维建议

### 生成报告

1. 在"报告摘要"区域，点击"生成日报"或"生成周报"按钮
2. 等待报告生成完成（约1-5秒）
3. 报告自动保存到 `logs/reports/` 目录
4. 报告列表自动更新，显示最新生成的报告

### 查看历史报告

1. 在"报告摘要"区域的报告列表中，找到要查看的报告
2. 点击对应行的"查看"按钮
3. 在弹出的窗口中查看报告详情（JSON格式）
4. 报告包含完整的分析数据和建议

### 调整分析周期

1. 在顶部选择"分析天数"下拉框
2. 选择合适的分析周期：
   - **1天**: 适合快速诊断当前问题
   - **3天**: 适合近期性能分析
   - **7天**: 默认设置，适合周性能分析
   - **14天**: 适合双周趋势分析
   - **30天**: 适合月度性能评估
3. 选择后自动刷新数据

### 手动刷新数据

1. 点击顶部的"刷新"按钮
2. 等待数据更新完成（约1-3秒）
3. 状态栏显示更新时间

## 注意事项

### 1. 数据依赖
- 仪表盘依赖 `src.monitor.history_analyzer` 模块
- 需要历史监控数据才能正常显示
- 如果没有历史数据，图表可能为空

### 2. 性能影响
- 自动更新间隔为1小时，对性能影响很小
- 手动刷新会触发数据分析，可能需要1-3秒
- 生成报告会占用一定CPU资源

### 3. 报告存储
- 报告保存在 `logs/reports/` 目录
- 报告格式为JSON
- 建议定期清理旧报告以节省磁盘空间

### 4. 图表显示
- 需要安装 `pyqtgraph` 库
- 如果图表显示异常，检查pyqtgraph版本
- 建议使用 pyqtgraph >= 0.12.0

### 5. 依赖要求
- **必需**: PyQt6, pyqtgraph
- **必需模块**: 
  - `src.monitor.history_analyzer`
  - `src.monitor.metrics_collector`
  - `src.monitor.data_collector`

## 集成建议

### 1. 菜单集成
```python
from src.ui.history_dashboard import HistoryDashboard

# 在主窗口的菜单栏中添加
def show_history_dashboard(self):
    if not hasattr(self, 'history_dashboard') or self.history_dashboard is None:
        self.history_dashboard = HistoryDashboard(self)
    self.history_dashboard.show()
    self.history_dashboard.raise_()
    self.history_dashboard.activateWindow()
```

### 2. 工具栏集成
```python
# 在主窗口的工具栏中添加
history_action = QAction(QIcon("icons/history.png"), "历史数据分析", self)
history_action.triggered.connect(self.show_history_dashboard)
toolbar.addAction(history_action)
```

### 3. 快捷键集成
```python
from PyQt6.QtGui import QShortcut, QKeySequence

# 添加快捷键 Ctrl+Shift+H
shortcut = QShortcut(QKeySequence("Ctrl+Shift+H"), self)
shortcut.activated.connect(self.show_history_dashboard)
```

### 4. 定时提醒
```python
# 定期提醒用户查看历史数据
def check_performance_alerts(self):
    from src.monitor.history_analyzer import analyze_oom_risks
    
    oom_data = analyze_oom_risks(7)
    risk_level = oom_data.get("data", {}).get("overall_risk", "")
    
    if risk_level in ["高", "中高"]:
        QMessageBox.warning(
            self, 
            "性能警告", 
            f"检测到OOM风险等级为{risk_level}，建议查看历史数据分析仪表盘"
        )
```

## 限制

1. **数据范围**: 最多分析30天的历史数据
2. **报告数量**: 报告列表最多显示5份最新报告
3. **更新频率**: 自动更新间隔固定为1小时
4. **图表类型**: 当前仅支持折线图
5. **导出功能**: 暂不支持图表导出为图片

## 故障排除

### 问题1: 图表无数据显示
**原因**: 没有历史监控数据  
**解决**: 运行程序一段时间后再查看，或检查监控模块是否正常工作

### 问题2: 报告生成失败
**原因**: 缺少历史数据或权限不足  
**解决**: 检查 `logs/reports/` 目录是否存在且有写入权限

### 问题3: pyqtgraph导入失败
**原因**: 未安装pyqtgraph库  
**解决**: 运行 `pip install pyqtgraph`

### 问题4: 图表显示异常
**原因**: pyqtgraph版本不兼容  
**解决**: 升级pyqtgraph到最新版本
