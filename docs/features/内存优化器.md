# 内存优化器 (MemoryOptimizer)

## 功能概述

内存优化器是VisionAI-ClipsMaster的核心性能组件，提供智能的内存管理、模型缓存和动态卸载机制，确保应用在有限内存环境下稳定运行。

## 功能特性

### 1. 智能内存监控
- **实时监控**：持续监控系统和进程内存使用情况
- **内存压力检测**：自动检测内存压力等级（正常/警告/紧急）
- **阈值管理**：可配置的内存使用阈值

### 2. LRU缓存管理
- **模型缓存**：缓存最近使用的AI模型，避免重复加载
- **数据缓存**：缓存处理过的数据，提高响应速度
- **自动驱逐**：基于LRU算法和内存限制自动清理缓存

### 3. 内存清理机制
- **轻量级清理**：定期执行Python垃圾回收
- **强制清理**：内存压力大时清空所有缓存
- **紧急清理**：内存严重不足时的激进清理策略

### 4. 回调机制
- **清理回调**：支持注册自定义清理函数
- **灵活扩展**：其他模块可以注册自己的内存清理逻辑

## 核心组件

### MemoryStats
内存统计信息数据类：
- `total_mb`: 系统总内存（MB）
- `available_mb`: 可用内存（MB）
- `used_mb`: 已使用内存（MB）
- `percent`: 内存使用百分比
- `process_mb`: 当前进程内存使用（MB）

### LRUCache
LRU缓存实现：
- 支持最大缓存数量限制
- 支持内存使用量限制
- 线程安全
- 自动驱逐策略

### MemoryOptimizer
主优化器类：
- 内存监控
- 缓存管理
- 清理调度
- 统计报告

## 使用方法

### 1. 获取全局实例

```python
from src.performance.memory_optimizer import get_memory_optimizer

optimizer = get_memory_optimizer()
```

### 2. 获取内存统计

```python
stats = optimizer.get_memory_stats()
print(f"进程内存: {stats.process_mb:.1f}MB")
print(f"系统内存使用率: {stats.percent:.1f}%")
```

### 3. 检查内存压力

```python
pressure = optimizer.check_memory_pressure()
# 返回: "normal", "warning", "emergency"
```

### 4. 缓存模型

```python
# 缓存模型
optimizer.cache_model("qwen-2.5-1.5b", model_instance, memory_mb=1500)

# 获取缓存的模型
model = optimizer.get_cached_model("qwen-2.5-1.5b")
```

### 5. 缓存数据

```python
# 缓存数据
optimizer.cache_data("processed_video_123", data, memory_mb=50)

# 获取缓存的数据
data = optimizer.get_cached_data("processed_video_123")
```

### 6. 注册清理回调

```python
def my_cleanup():
    # 自定义清理逻辑
    print("清理我的资源...")

optimizer.register_cleanup_callback(my_cleanup)
```

### 7. 手动清理

```python
# 轻量级清理
optimizer.cleanup()

# 强制清理
optimizer.force_cleanup()
```

### 8. 使用装饰器

```python
from src.performance.memory_optimizer import optimize_memory_usage

@optimize_memory_usage()
def process_large_video(video_path):
    # 处理大视频文件
    # 函数执行前会检查内存压力
    # 函数执行后会进行轻量级清理
    pass
```

## 集成建议

### 作为后台服务运行

内存优化器已经在初始化时自动启动监控，无需手动启动。它会：
1. 每30秒检查一次内存使用情况
2. 当内存使用率超过80%时，执行轻量级清理
3. 当内存使用率超过90%时，执行强制清理

### 在UI中显示状态

可以在设置页面或状态栏显示内存优化器的状态：

```python
stats = optimizer.get_optimization_stats()
# 显示:
# - 进程内存使用
# - 系统内存使用率
# - 模型缓存状态
# - 数据缓存状态
# - 内存压力等级
```

### 提供手动控制

可以在设置页面添加按钮：
- "清理内存"按钮：调用 `optimizer.force_cleanup()`
- "查看内存统计"按钮：显示详细的内存使用情况

## 配置参数

### 内存限制
- 默认内存限制：3800MB
- 模型缓存限制：70%（2660MB）
- 数据缓存限制：20%（760MB）

### 监控间隔
- 默认监控间隔：30秒

### 清理阈值
- 轻量级清理阈值：80%
- 强制清理阈值：90%

## 性能影响

### 优点
- **减少内存占用**：通过智能缓存和清理，显著降低内存使用
- **提高响应速度**：缓存常用模型和数据，避免重复加载
- **防止OOM**：主动监控和清理，防止内存溢出

### 注意事项
- **缓存驱逐**：频繁访问的模型可能被驱逐，导致重新加载
- **清理开销**：强制清理会暂停应用，可能影响用户体验
- **监控开销**：后台监控会占用少量CPU资源

## 故障排除

### 问题1：内存使用仍然很高
**原因**：可能有内存泄漏或大对象未释放
**解决方案**：
1. 检查是否有循环引用
2. 确保大对象使用后及时删除
3. 调用 `optimizer.force_cleanup()` 强制清理

### 问题2：模型频繁重新加载
**原因**：缓存空间不足，模型被频繁驱逐
**解决方案**：
1. 增加内存限制
2. 减少同时使用的模型数量
3. 使用更小的量化模型

### 问题3：清理后内存未释放
**原因**：Python的垃圾回收机制延迟释放
**解决方案**：
1. 多次调用 `gc.collect()`
2. 等待一段时间让系统回收内存
3. 重启应用

## 未来改进方向
