# MetaClipEngine功能说明

## 功能概述

**MetaClipEngine**(元数据驱动剪辑引擎)是一个基于元数据的视频剪辑生成及处理系统。它通过统一的元数据格式描述剪辑操作,支持跨平台、跨格式的剪辑项目导出。

### 核心特性

1. **元数据驱动**: 使用JSON格式的元数据描述剪辑操作,而不是直接操作视频文件
2. **零拷贝处理**: 集成ZeroCopyPipeline,避免不必要的数据复制
3. **内存映射**: 使用MemMapEngine处理大文件,减少内存占用
4. **可扩展架构**: 支持多种剪辑操作类型,易于扩展新功能

## 工作原理

### 1. 元数据格式

MetaClipEngine使用`MetaClip`数据类描述剪辑操作:

```python
@dataclass
class MetaClip:
    operation: str                        # 操作类型(slice/concat/trim等)
    src: Union[str, List[str]]            # 源文件路径或路径列表
    in_point: Optional[float] = None      # 入点时间(秒)
    out_point: Optional[float] = None     # 出点时间(秒)
    codec: str = "copy"                   # 编解码方式
    params: Dict[str, Any] = {}           # 附加参数
    id: str = uuid                        # 唯一标识符
    children: List['MetaClip'] = []       # 子操作
```

### 2. 支持的操作类型

| 操作类型 | 说明 | 示例 |
|---------|------|------|
| **SLICE** | 切片操作 | 从视频中提取某个时间段 |
| **CONCAT** | 连接操作 | 将多个视频片段连接成一个 |
| **TRIM** | 修剪操作 | 修剪视频的开头或结尾 |
| **SPEED** | 速度调整 | 加速或减速视频播放 |
| **FILTER** | 滤镜效果 | 应用视觉效果(模糊、锐化等) |
| **TRANSITION** | 转场效果 | 添加片段间的过渡效果 |
| **AUDIO** | 音频操作 | 调整音量、添加背景音乐 |
| **TEXT** | 文本叠加 | 添加字幕或文字 |
| **OVERLAY** | 视频叠加 | 画中画效果 |
| **TRANSFORM** | 变换操作 | 旋转、缩放、平移 |
| **CROP** | 裁剪操作 | 裁剪视频画面 |
| **COMPOSITE** | 合成操作 | 多层视频合成 |

### 3. 编解码模式

| 模式 | 说明 | 性能 | 质量 |
|------|------|------|------|
| **COPY** | 直接复制,不重新编码 | 最快 | 无损 |
| **TRANSCODE** | 重新编码 | 慢 | 可调 |
| **LOSSLESS** | 无损编码 | 较慢 | 最高 |
| **LOSSY** | 有损编码 | 较快 | 可调 |

### 4. 处理流程

```
用户输入 → MetaClip元数据 → MetaClipEngine → 处理器 → 输出结果
                                    ↓
                            ZeroCopyPipeline
                                    ↓
                            MemMapEngine
```

## 使用场景

### 场景1: 批量视频切片

**需求**: 从一个长视频中提取多个精彩片段

**元数据示例**:
```json
{
  "operation": "slice",
  "src": "long_video.mp4",
  "in_point": 10.5,
  "out_point": 25.3,
  "codec": "copy",
  "params": {
    "output": "clip_001.mp4"
  }
}
```

**优势**:
- 使用copy模式,无需重新编码,速度快
- 零拷贝处理,内存占用低
- 可以批量处理多个切片

### 场景2: 视频片段连接

**需求**: 将多个视频片段连接成一个完整视频

**元数据示例**:
```json
{
  "operation": "concat",
  "src": ["clip_001.mp4", "clip_002.mp4", "clip_003.mp4"],
  "codec": "copy",
  "params": {
    "output": "final_video.mp4"
  }
}
```

**优势**:
- 支持多个文件连接
- 自动检查文件存在性
- 保持原始视频质量

### 场景3: 复杂剪辑流程

**需求**: 先切片,再连接,最后添加转场效果

**元数据示例**:
```json
{
  "operation": "composite",
  "children": [
    {
      "operation": "slice",
      "src": "video1.mp4",
      "in_point": 0,
      "out_point": 10
    },
    {
      "operation": "transition",
      "params": {"type": "fade", "duration": 1.0}
    },
    {
      "operation": "slice",
      "src": "video2.mp4",
      "in_point": 5,
      "out_point": 15
    }
  ]
}
```

**优势**:
- 支持嵌套操作
- 一次性描述完整流程
- 易于保存和复用

## UI集成方案

### 方案1: 工具菜单 + 对话框 (推荐)

**UI位置**: 工具菜单 → "元数据剪辑编辑器"

**对话框内容**:
- **左侧**: 操作列表(可拖拽排序)
- **右侧**: 当前操作的参数编辑
- **底部**: 预览按钮、导出按钮

**优点**:
- 专业的剪辑工作流
- 可视化操作编辑
- 支持复杂的嵌套操作

**缺点**:
- 开发工作量大(约8小时)
- 需要学习成本

### 方案2: 快捷操作按钮

**UI位置**: 视频处理标签页 → 新增"快捷剪辑"区域

**功能**:
- "快速切片"按钮 - 输入时间点,快速切片
- "批量连接"按钮 - 选择多个文件,快速连接
- "导出元数据"按钮 - 保存当前操作为JSON

**优点**:
- 简单易用
- 开发工作量小(约3小时)
- 适合快速操作

**缺点**:
- 功能有限
- 不支持复杂操作

### 方案3: 后台自动化

**UI位置**: 无UI,作为后台功能

**使用方式**:
- 在"生成爆款SRT"流程中自动使用
- 自动生成MetaClip元数据
- 自动执行剪辑操作

**优点**:
- 无需用户干预
- 与现有流程无缝集成
- 开发工作量最小(约2小时)

**缺点**:
- 用户无法手动控制
- 功能不可见

### 方案4: 元数据文件导入/导出

**UI位置**: 文件菜单 → "导入元数据剪辑" / "导出元数据剪辑"

**功能**:
- 导入JSON格式的MetaClip文件
- 执行剪辑操作
- 导出剪辑结果

**优点**:
- 支持外部工具生成的元数据
- 可以保存和复用剪辑方案
- 开发工作量中等(约5小时)

**缺点**:
- 需要用户了解JSON格式
- 不够直观

## 推荐方案

**推荐方案3**(后台自动化),原因:
1. 与现有"生成爆款SRT"流程完美集成
2. 用户无需学习新功能
3. 开发工作量最小
4. 可以后续扩展为方案2或方案1

**集成步骤**:
1. 在`WorkflowManager`中集成MetaClipEngine
2. 在视频生成步骤中使用MetaClip描述剪辑操作
3. 自动执行剪辑并生成最终视频

|------|---------|---------|--------|

## 技术细节

### 依赖模块

- `src.exporters.memmap_engine` - 内存映射引擎
- `src.exporters.stream_pipe` - 零拷贝管道
- `src.utils.log_handler` - 日志处理
- `src.utils.exceptions` - 异常处理

### 配置文件

无需额外配置文件,所有参数通过MetaClip元数据传递。

### 线程安全

MetaClipEngine是线程安全的,可以在多线程环境中使用。

## 总结

MetaClipEngine是一个强大的元数据驱动剪辑引擎,适合集成到现有的视频处理流程中。推荐使用**方案3**(后台自动化)进行集成,可以在不增加用户学习成本的情况下,提升视频处理的灵活性和效率。
