# 剪映智能导出功能 - 用户使用指南

## 📖 功能概述

VisionAI-ClipsMaster 现在支持**智能剪映导出**功能，可以自动检测剪映安装路径和草稿目录，一键将生成的视频项目导出到剪映并自动启动剪映软件。

### ✨ 主要特性

- ✅ **自动路径检测**：无需手动配置，自动检测剪映草稿目录和安装路径
- ✅ **智能缓存**：首次检测后缓存配置，后续使用更快速
- ✅ **手动选择支持**：如果自动检测失败，可以手动选择目录
- ✅ **一键启动**：导出完成后自动启动剪映软件
- ✅ **友好提示**：详细的进度提示和错误处理

---

## 🚀 快速开始

### 步骤1：准备视频项目

1. 在VisionAI-ClipsMaster中完成视频处理流程
2. 点击**"生成工程文件"**按钮生成项目数据

### 步骤2：导出到剪映

1. 点击**"📱 导出到剪映"**按钮
2. 程序会自动：
   - 检测剪映草稿目录
   - 生成剪映草稿文件
   - 复制到剪映草稿目录
   - 启动剪映软件

### 步骤3：在剪映中编辑

1. 剪映启动后，在**"本地草稿"**中找到您的项目
2. 项目名称格式：`原项目名_日期时间`
3. 双击打开即可开始编辑

## 🔧 详细使用说明

### 自动检测模式（推荐）

**适用场景**：剪映安装在默认位置

**操作步骤**：
1. 点击"导出到剪映"按钮
2. 等待自动检测完成（通常1-2秒）
3. 检测成功后自动导出并启动剪映

**检测逻辑**：
- 检查Windows注册表中的剪映配置
- 检查剪映配置文件
- 检查常见默认路径：
  - `C:\Users\<用户名>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft\`
  - 其他常见安装位置

### 手动选择模式

**适用场景**：
- 剪映安装在非标准位置
- 自定义了草稿目录
- 自动检测失败

**操作步骤**：
1. 点击"导出到剪映"按钮
2. 如果自动检测失败，会弹出提示对话框
3. 点击"是"选择手动选择草稿目录
4. 在文件选择对话框中找到剪映草稿目录
5. 选择后程序会保存配置，下次自动使用

**如何找到剪映草稿目录**：
1. 打开剪映软件
2. 点击"设置" → "通用"
3. 查看"草稿位置"设置
4. 复制该路径并在文件选择对话框中导航到该位置

## 📁 配置文件

### 配置文件位置

```
VisionAI-ClipsMaster/
└── config/
    └── jianying_paths.json
```

### 配置文件格式

```json
{
  "draft_directory": "C:\\Users\\用户名\\AppData\\Local\\JianyingPro\\User Data\\Projects\\com.lveditor.draft",
  "install_path": "C:\\Program Files\\JianyingPro\\JianyingPro.exe"
}
```

### 重置配置

如果需要重新检测路径，可以：
1. 删除 `config/jianying_paths.json` 文件
2. 重新运行导出功能，程序会重新检测

## ❓ 常见问题

### Q1: 提示"无法检测到剪映草稿目录"怎么办？

**A**: 这通常是因为：
- 剪映未安装
- 剪映安装在非标准位置
- 草稿目录被修改

**解决方法**：
1. 确认剪映已正确安装
2. 使用手动选择模式指定草稿目录
3. 检查剪映设置中的草稿位置

### Q2: 导出成功但在剪映中找不到草稿？

**A**: 请检查：
1. 剪映是否已刷新草稿列表（重启剪映）
2. 草稿目录是否正确
3. 查看导出成功提示中的草稿位置，手动打开该文件夹确认文件存在

### Q3: 剪映无法自动启动？

**A**: 可能原因：
- 剪映安装路径检测失败
- 剪映未安装或已卸载

**解决方法**：
1. 手动打开剪映
2. 在"本地草稿"中找到导出的项目
3. 如果需要自动启动功能，可以手动设置剪映安装路径

### Q4: 导出的草稿文件在哪里？

**A**: 草稿文件位置：
- **最终位置**：剪映草稿目录（由剪映设置决定）
- **临时位置**：`VisionAI-ClipsMaster/data/output/temp_jianying_drafts/`（导出后自动清理）

### Q5: 可以同时导出多个项目吗？

**A**: 可以。每次导出都会生成带时间戳的唯一项目名称，不会覆盖之前的项目。

## 🎯 最佳实践

### 1. 首次使用

- 确保剪映已安装并至少运行过一次
- 让程序自动检测路径，成功后会缓存配置
- 如果自动检测失败，使用手动选择并确保选择正确的目录

### 2. 项目命名

- 生成工程文件时使用有意义的项目名称
- 导出时会自动添加时间戳，便于区分不同版本

### 3. 草稿管理

- 定期在剪映中清理不需要的草稿
- 重要项目建议在剪映中导出为独立文件

### 4. 故障排除

- 如果遇到问题，查看程序日志（`logs/` 目录）
- 尝试删除配置文件重新检测
- 确保剪映版本为最新版本
