## 1. 问题诊断

### 1.1 问题现象

用户在UI中点击"取消"按钮后，下载进程继续运行，表现为：
- 对话框关闭，但终端显示下载继续进行
- 需要等待几分钟才能完全停止
- 不完整的文件未被清理

### 1.2 根本原因

**核心问题**：使用了ModelScope的`snapshot_download`阻塞调用

```python
# 旧代码（问题代码）
model_dir = ms_snapshot_download(
    repo_id,
    cache_dir=str(local_dir.parent),
)
```

**技术分析**：
1. `snapshot_download`是一个**阻塞调用**，无法被中断
2. 即使设置`is_cancelled=True`，下载仍会继续直到完成或失败
3. 取消检查只能在下载完成后执行，为时已晚

**证据**：
```
2025-11-02 10:14:27,544 - 用户取消下载: Qwen3-1.7B-Instruct-FP16
2025-11-02 10:14:27,723 - ⚠️ 用户取消下载，停止进度监控
# 但下载继续：
Downloading [model-00002-of-00002.safetensors]:  20%|███▏  | 119M/594M [00:39<02:50, 2.92MB/s]
```

## 2. 修复方案

### 2.1 架构变更

**从阻塞调用改为逐文件下载**：

```python
# 新代码（修复后）
if is_modelscope:
    # 🔧 使用ModelScope API逐个下载文件（支持取消）
    logger.info(f"📡 使用ModelScope API逐个下载文件")
    
    try:
        from modelscope.hub.api import HubApi
        
        # 获取文件列表
        api = HubApi()
        files_to_download = api.get_model_files(model_id=repo_id, recursive=True)
        
        # 计算总大小
        total_size = sum(int(f.get('Size', 0)) for f in files_to_download)
        
        # 🔧 逐个下载文件（使用_download_file方法，支持取消）
        for file_idx, file_info in enumerate(files_to_download):
            # 检查是否已取消
            if self.is_cancelled:
                logger.warning("⚠️ 用户取消下载")
                self._cleanup_snapshot_download(local_dir.parent, force_delete_all=True)
                raise Exception("用户取消下载")
            
            # 下载单个文件
            file_url = f"{endpoint}/api/v1/models/{repo_id}/repo?Revision=master&FilePath={file_name}"
            success = self._download_file(file_url, target_file_path, file_size)
            
            if not success:
                if self.is_cancelled:
                    self._cleanup_snapshot_download(local_dir.parent, force_delete_all=True)
                    raise Exception("用户取消下载")
```

### 2.2 关键改进

1. **文件级别的取消检查**：
   - 在每个文件下载之前检查`is_cancelled`
   - 在每个文件下载失败时检查`is_cancelled`

2. **使用现有的`_download_file`方法**：
   - 该方法内部已经支持取消检查（在每个chunk下载时）
   - 实现了真正的"立即取消"

3. **自动清理**：
   - 取消时调用`_cleanup_snapshot_download(force_delete_all=True)`
   - 删除整个下载目录，不留残留文件

## 4. 技术细节

### 4.1 ModelScope文件下载URL格式

```
https://www.modelscope.cn/api/v1/models/{repo_id}/repo?Revision=master&FilePath={file_name}
```

**示例**：
```
https://www.modelscope.cn/api/v1/models/Qwen/Qwen3-1.7B/repo?Revision=master&FilePath=config.json
```

### 4.2 文件信息获取

```python
from modelscope.hub.api import HubApi

api = HubApi()
files = api.get_model_files(model_id=repo_id, recursive=True)

# 文件信息结构（dict或对象）
for file_info in files:
    file_name = file_info.get('Path', file_info.get('Name', ''))
    file_size = int(file_info.get('Size', 0))
```

### 4.3 取消检查点

1. **文件循环开始时**：
   ```python
   for file_idx, file_info in enumerate(files_to_download):
       if self.is_cancelled:  # 检查点1
           raise Exception("用户取消下载")
   ```

2. **文件下载过程中**（在`_download_file`方法内）：
   ```python
   for chunk in response.iter_content(chunk_size=8192):
       if self.is_cancelled:  # 检查点2
           return False
   ```

3. **文件下载失败时**：
   ```python
   if not success:
       if self.is_cancelled:  # 检查点3
           raise Exception("用户取消下载")
   ```
