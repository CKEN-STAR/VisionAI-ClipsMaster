# HF-Mirror CDN重定向问题修复报告

**修复时间**：2025-11-01  
**问题类型**：HF-Mirror CDN重定向导致下载超时  
**严重程度**：🔴 严重（导致Qwen3-1.7B模型无法下载）

---

## 执行摘要

在UI中尝试下载Qwen3-1.7B模型时失败，经过深度排查发现根本原因是HF-Mirror镜像源将大文件请求重定向到了`cas-bridge.xethub.hf.co` CDN服务器，该服务器在中国大陆无法访问，导致下载超时失败。

**根本原因**：
- HF-Mirror对Qwen3-1.7B的大文件（如`model-00001-of-00002.safetensors`）会重定向到`cas-bridge.xethub.hf.co`
- 该CDN服务器在中国大陆无法访问或速度极慢
- 导致下载在30秒后超时失败

**修复方案**：
1. 调整镜像源优先级：HuggingFace官方源优先，HF-Mirror作为备用
2. 添加CDN重定向检测和警告日志
3. 保留416错误处理和进度更新功能

**修复结果**：
- ✅ 识别并记录HF-Mirror CDN重定向问题
- ✅ 调整镜像源优先级（HuggingFace官方源优先）
- ✅ 416错误处理正确
- ✅ 进度更新显示正常
- ✅ 所有现有功能保持兼容

## 问题诊断

### 1. 问题现象

**用户报告**：
- 在UI中点击下载Qwen3-1.7B模型
- 前5个小文件下载成功（LICENSE, README.md, config.json, generation_config.json, merges.txt）
- 第6个大文件（model-00001-of-00002.safetensors）开始下载后卡住
- 等待约30秒后显示"网络请求错误"
- 下载失败

**日志分析**：
```
2025-11-01 22:06:44,616 - INFO - 📡 发送GET请求: https://hf-mirror.com/Qwen/Qwen3-1.7B/resolve/main/model-00001-of-00002.safetensors
... (等待30秒，没有任何进度日志)
2025-11-01 22:07:15,301 - ERROR - 网络请求错误: HTTPSConnectionPool(host='cas-bridge.xethub.hf.co', port=443): Read timed out. (read timeout=30)
```

### 2. 根本原因分析

**HF-Mirror的工作机制**：
1. 用户请求：`https://hf-mirror.com/Qwen/Qwen3-1.7B/resolve/main/model-00001-of-00002.safetensors`
2. HF-Mirror返回HTTP 302重定向到：`https://cas-bridge.xethub.hf.co/...`
3. 浏览器/requests库自动跟随重定向
4. 尝试从`cas-bridge.xethub.hf.co`下载文件

**问题所在**：
- `cas-bridge.xethub.hf.co`是HF-Mirror使用的CDN服务器
- 该服务器在中国大陆**无法访问或速度极慢**
- 导致下载请求在30秒后超时

**为什么小文件成功，大文件失败？**
- 小文件（几KB）：HF-Mirror直接返回，不重定向到CDN
- 大文件（几GB）：HF-Mirror重定向到CDN服务器
- 因此小文件下载成功，大文件下载失败

### 3. 与Qwen2.5的对比

**Qwen2.5（正常工作）**：
- 配置：`model_format: "gguf"`
- 下载：直接下载GGUF量化模型（单个文件，约4GB）
- 结果：成功（可能是GGUF文件不触发CDN重定向）

**Qwen3-1.7B（失败）**：
- 配置：`model_format: "huggingface"`
- 下载：下载HuggingFace原始模型（多个safetensors文件，每个约2GB）
- 结果：失败（safetensors文件触发CDN重定向）

## 修复方案

### 1. 调整镜像源优先级

**修改文件**：`configs/models/available_models/qwen3-1.7b-zh.yaml`

**修改前**：
```yaml
source_priority:
  - hf_mirror   # 优先：国内高速镜像（hf-mirror.com）
  - huggingface # 备用：官方源（永不失效）
```

**修改后**：
```yaml
source_priority:
  - huggingface # 优先：官方源（稳定可靠）
  - hf_mirror   # 备用：国内高速镜像（小文件快，大文件可能有问题）
```

**原理**：
- HuggingFace官方源虽然在中国大陆速度较慢，但**稳定可靠**
- HF-Mirror对大文件有CDN重定向问题，作为备用
- 如果官方源失败，会自动切换到HF-Mirror

### 2. 添加CDN重定向检测

**修改文件**：`src/core/enhanced_model_downloader.py`

**修改位置**：第643-656行

**修改内容**：
```python
except requests.exceptions.RequestException as e:
    # 特殊处理416错误：文件已完整下载
    if hasattr(e, 'response') and e.response is not None and e.response.status_code == 416:
        logger.info(f"✅ 文件已完整下载: {target_path.name} ({self._format_size(resume_pos)})")
        return True
    
    # 🔧 检测HF-Mirror CDN重定向问题
    error_str = str(e)
    if 'cas-bridge.xethub.hf.co' in error_str or 'xethub' in error_str:
        logger.warning(f"⚠️ 检测到HF-Mirror CDN重定向问题（xethub不可访问）")
        logger.warning(f"⚠️ 建议切换到HuggingFace官方源")
    
    logger.error(f"网络请求错误: {str(e)}")
    return False
```

**原理**：
- 检测错误信息中是否包含`xethub`关键字
- 如果包含，输出警告日志，提示用户CDN重定向问题
- 帮助用户理解下载失败的原因

### 3. 清理调试日志

**修改文件**：`src/core/enhanced_model_downloader.py`

**删除的调试日志**：
- 第288-293行：删除`logger.info(f"🔗 开始下载: {file_url}")`
- 第506-523行：删除`_download_file`方法中的详细调试日志
- 第536-563行：删除GET请求和数据接收的详细日志

**原理**：
- 调试日志已完成使命，不再需要
- 保持代码简洁，减少日志噪音
